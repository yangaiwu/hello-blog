# Spec — Issue #21 娱乐秀场直播站点（Web + 腾讯云 CSS）

> 来源：Issue #21 的 Spec 评论（Issue Agent 发布，评级 ready）。本文件是开发侧对同一规格的落地记录，不改变验收标准。

## 目标

一个娱乐秀场形态的直播 Web 站点，跑通「开播 → 观看 → 弹幕」闭环，作为后续礼物/连麦/回放的基础骨架。

## 范围

### In Scope

1. 房间列表页：展示进行中/历史房间（封面占位、主播名、状态、在线人数）。
2. 开播页：创建房间 → 生成腾讯云 CSS 推流地址（RTMP，txSecret/txTime 本地签名）与播放地址（HLS/FLV）→ 展示 OBS 服务器与串流密钥 → 结束直播。
3. 观看页：H5 播放器（hls.js 优先，flv.js 回退），demo 模式展示占位提示且不报错。
4. 弹幕：WebSocket（同端口）房间内实时广播，昵称 1–30 字、内容 1–200 字、同连接每秒最多 1 条；历史弹幕回显。
5. 持久化：SQLite 保存房间与弹幕。

### Out of Scope

礼物打赏、连麦（RTC）、录制回放、数据统计、登录鉴权、移动 App；腾讯云侧域名/CNAME/模板配置由用户在控制台完成。

## 外部依赖

`CSS_PUSH_DOMAIN` / `CSS_PLAY_DOMAIN` / `CSS_PUSH_KEY`（可选 `CSS_BIZID`、`CSS_APP_NAME`、`CSS_PLAY_KEY`）。任一必需项缺失 → demo 模式，服务正常启动，闭环验收不受影响。

## 验收标准

- [ ] 首页列出已创建房间，可进入观看页
- [ ] 创建房间后返回可用的 RTMP 推流地址与 HLS/FLV 播放地址；结束直播后状态变为 ended
- [ ] 观看页能加载播放地址（demo 模式展示占位提示，不报错）
- [ ] 同房间两个浏览器窗口弹幕实时互通（无需刷新），历史弹幕可回显
- [ ] 弹幕长度/频率越界被拒绝，返回明确错误
- [ ] 未配置 CSS 凭据时服务可启动（demo 模式），README 已说明
- [ ] `python -m pytest -q` 全部通过
- [ ] 一次性启动自检返回 200
